# Releases

## v0.0.1 — Initial public release

Initial public release of `@preeternal/jws-verifier`.

### Added

- Compact ES256 JWS verification with X.509 certificate-chain validation.
- Offline and online verification modes with optional OCSP revocation checks.
- Synchronous transaction ID extraction from App Receipts and transaction
  receipts.
- ESM package for Node.js 22+ and Cloudflare Workers.
